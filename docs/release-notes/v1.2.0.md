# v1.2.0 语料扩充与岗位过滤

## 数据
- 新增小红书招聘爬虫（`pageQueryPosition` 免签名直连）：社招 864 + 校招 508，清洗后 1284 条完整 JD（含 jobType / publishTime）
- 语料 **3302 → 4582** 条，覆盖公司 **77 → 78** 家（原始 5013 → 过短 7 + 非 AI 工程岗 4 + 重复 420）

## 新增
- **岗位标题过滤器**（`src/data/job_filter.py`）：34 词土木/建筑/施工类黑名单 + 31 词 AI 白名单保护（「建筑智能化 AI 产品经理」「模型结构优化工程师」等不会被误杀），构建时剔除 4 条非 AI 工程岗（4586 → 4582）；`configs/dataset.yaml` 的 `cleaning.title_filter` 可开关与覆盖词表
- **差距报告按专业给建议**：报告页读取简历解析出的专业，用 7 类专业簇（计算机/数理/自动化/土建交通/经管/生物医药/人文）匹配迁移路径，未识别专业时不展示该区块，也不再预设「道桥」背景
- **Streamlit 云端保活**：GitHub Actions 每 6 小时 HTTP 探测，失败自动用 Playwright 真实浏览器唤醒，避免免费实例休眠
- **README 截图脚本**（`scripts/capture_screenshots.py`）：自动起 headless 服务 + Playwright 截图（隐藏 Deploy 工具栏），预览图可随数据一键重截

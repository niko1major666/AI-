# 项目简报（Project Brief）

## 项目名称
AI 岗位技能差距分析系统（ai-skill-gap）

## 项目定位
面向**非科班（传统工科，作者为道桥背景）求职者**的个人项目，分析目标 AI 岗位所需技能，与自身简历对比，输出技能差距报告与学习优先级。体现 **NLP 信息抽取 + 语义匹配 + 工程落地**能力。

## 核心需求与目标
1. **数据采集**：采集真实 AI 岗位 JD（大厂 + AI 创业公司），当前 1878 条 / 76 家公司
2. **技能抽取**：从 JD 抽取细粒度技能实体（147 个标准技能）
3. **语义匹配**：简历/技能列表 → 目标岗位技能，计算匹配度
4. **差距诊断**：缺失技能 + 优先级（P0/P1/P2）+ 行业重要度 + 学习难度 + 学习资源 + 道桥迁移建议
5. **前端展示**：Streamlit 三页面（技能图谱 / 简历匹配 / 差距报告）
6. **简历解析**：正则 + DeepSeek LLM 增强（姓名、工作经历等）+ ATS 改进建议

## 项目范围（Source of Truth）
- 一条完整 NLP 落地链路：数据采集 → 技能抽取（双路）→ 语义匹配（双路）→ 差距诊断 → 前端可视化
- 差异化亮点：内置「道桥背景 → AI 技能」迁移映射
- 诚实标注所有实验结论（含失败案例）

## 作者背景
吉林大学 道路桥梁与渡河工程 大四，投递 AI+ 岗位。

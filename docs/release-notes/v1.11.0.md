## 踩坑（已写进 memory-bank/lessons.md 第 8、9 条）

- 初版把技能名写成「iOS 开发 / Android 开发」。「开发」是 JD 高频通用词，TF-IDF 字符 n-gram
  把它算成强信号，挤掉了 gold 里 Java 的 top-5 位次（resume Recall@5 0.2200→0.2000，刚好卡容差线）。
  改成专有名词 `iOS` / `Android` 后恢复 0.2200。
- 结论：**技能 name 只放专有名词**，通用词放 aliases 或不放；改词表后必须看 `eval_all.py` 的匹配表，
  不能只看抽取 F1。

# 简历数据处理与隐私说明

> 版本：2026-10-30  
> 适用范围：AI 岗位技能差距分析（Streamlit 应用，仓库 `niko1major666/AI-`）。  
> 本文是应用内隐私摘要的完整版。若两者不一致，以本文件为准，并会同步更新应用内摘要版本号。

## 1. 处理哪些数据

仅在用户主动上传时处理：

- 简历文件本身（PDF / DOCX / TXT / MD）及其解析出的文本；
- 从简历中提取的结构化信息：姓名、学历、学校、专业、工作年限、工作/实习/项目经历、技能关键词、邮箱、手机号；
- 用户在“差距报告”页输入的目标岗位、技能列表，以及从简历带入的专业名称；
- 运行过程中产生的必要访问日志（由部署平台/反向代理生成，本应用不主动建立用户画像）。

本应用**不要求注册账号**，也**不会把简历写入岗位数据库、项目目录或自建数据库**。

## 2. 处理目的与方式

1. 解析简历文本，提取技能与经历，用于：
   - 简历结构化展示与 ATS 改进建议；
   - 与岗位技能做匹配、生成技能画像与岗位推荐；
   - 在差距报告中给出针对 P0 缺口的简历补强建议。
2. 生成“AI 解读 + 学习计划”时，向 DeepSeek 发送目标岗位、技能名称与专业名称；**不发送简历原文**。

处理方式包括本地规则（正则/词表/匹配模型）与用户**可选开启**的第三方大模型增强。

## 3. 对外发送与用户授权

### 3.1 默认：不发送简历给第三方

用户未勾选“允许将脱敏后的简历前 6,000 字发送至 DeepSeek API”时：

- 简历只在应用服务进程内用本地规则解析；
- 不调用 DeepSeek 或其他第三方大模型；
- 仍可使用简历技能提取、ATS 建议、技能画像、岗位推荐与规则版学习路径。

### 3.2 可选：DeepSeek 简历结构化增强

只有用户主动勾选并点击上传后，才会发生以下外发：

- 接收方：DeepSeek API（`https://api.deepseek.com/chat/completions`，模型 `deepseek-chat`）；
- 内容：简历文本**前 6,000 字**；
- 发送前自动替换（脱敏）以下直接联系方式/标识：
  - 邮箱；
  - 中国大陆手机号；
  - 18 位身份证号；
  - 16–19 位银行卡号；
  - 带标签的微信号/QQ/WhatsApp；
  - 带“住址/地址/现居/居住地/通讯地址”标签的详细地址。
- 不发送：上传的原始文件、完整简历全文、本地提取出的邮箱/手机号。
- 频率限制：每个浏览器会话最多 10 次 AI 简历解析。

**脱敏的边界**：姓名、学校、公司、项目经历、成果描述等正文**不会被替换**，这些信息组合后仍可能识别到个人，因此 AI 增强**并非匿名化处理**。如简历包含你不想外发的信息，请关闭 AI 增强或先自行删改。

DeepSeek 对请求的处理、存储与跨境传输受其自身服务条款和隐私政策约束；本应用无法代替其作出承诺。请在使用前自行评估。

### 3.3 报告 AI 解读

“AI 解读 + 学习计划”会向 DeepSeek 发送目标岗位、技能名称与匹配统计；仅当用户开启了简历 AI 增强时，才额外发送从简历解析出的专业名称。不包含简历原文、邮箱、手机号或证件号。该功能在配置了 API key 时自动生成；未配置或无网络时自动使用规则模板。

## 4. 存储与保留

- 简历文件与解析文本：仅存在于当前 Streamlit 会话内存；刷新/关闭页面后会话结束，应用不再持有。
- 解析结果缓存：改为会话级（`st.session_state`），不使用跨会话的 `st.cache_data` 保存简历文本或解析结果。
- 岗位语料、技能词表、指标报告：公开的岗位数据与本项目产物，不包含用户简历。
- 部署平台（如 Streamlit Community Cloud）可能生成访问日志、错误日志或临时缓存；其保留期限由平台政策决定。本应用不主动导出或归档这些日志。
- 用户自行下载的报告（Markdown/Word）：保存在用户本地，由用户自行管理。

## 5. 上传与资源限制

| 限制 | 值 |
|---|---|
| 单文件大小 | ≤ 5 MB（同时在 `.streamlit/config.toml` 与服务端校验） |
| 支持类型 | PDF / DOCX / TXT / MD |
| PDF 页数 | ≤ 30 页（文字层与 OCR 均在页数校验后执行） |
| 解析文本长度 | ≤ 50,000 字 |
| DOCX 解压后大小 | ≤ 50 MB（防 zip bomb） |
| 每会话 AI 简历解析 | ≤ 10 次 |
| 单次外发简历文本 | ≤ 前 6,000 字 |

超过限制时应用会拒绝处理并提示原因，不会把文件写入磁盘。

## 6. 用户控制与权利

- **拒绝**：不勾选隐私同意，或保持 AI 增强关闭；仍可使用本地规则功能。
- **撤回**：关闭 AI 增强后重新上传，即可停止后续外发；已完成的第三方请求无法由本应用撤回。
- **清除**：刷新或关闭页面即可结束当前会话；本地下载的报告需用户自行删除。
- **更正**：简历内容由用户自行修改后重新上传。
- **咨询/投诉**：通过项目仓库 Issues 联系维护者（`https://github.com/niko1major666/AI-/issues`）。涉及部署平台日志的删除请求，需同时联系对应托管平台。

由于本应用不建立账号体系、不持久化简历，通常无法凭邮箱/姓名检索并删除某次会话的数据；请在会话内直接关闭页面。

## 7. 安全措施与剩余风险

已采取：

- 上传类型/大小/页数/文本长度校验；
- DOCX 解压大小限制；
- AI 外发前强制 PII 正则脱敏与字符截断；
- 简历解析结果会话级缓存，避免跨会话命中；
- API key 仅从环境变量或 Streamlit secrets 读取，不写入仓库。

剩余风险：

- 正则脱敏无法覆盖所有写法（如无标签的地址、姓名嵌入正文、图片中的文字、特殊格式证件号）；
- 第三方 API、网络传输与托管平台日志不受本应用完全控制；
- 简历内容本身可能包含敏感信息（健康、宗教、政治面貌、家庭信息等），请在上传前自行删减。

## 8. 未成年人

本应用面向求职者，不面向未成年人。请勿上传未成年人简历或未经监护人同意的个人信息。

## 9. 变更

隐私说明版本号会显示在应用内。每次改变外发字段、脱敏范围、保存方式或第三方服务时，都会更新版本号与本文件，并要求用户重新确认。

本应用提供技能差距分析与学习建议，不构成录用、法律或职业决策承诺；岗位信息来自公开招聘页面，可能存在延迟或误差。请勿将本应用输出作为对任何个人的自动决策依据。

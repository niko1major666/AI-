# v1.9.0 华为数据源修复：2 条 → 219 条

华为从 v1.6.0 起一直是 2 条 / 发布覆盖 0%，被标「⚠️ 关注」。本轮查明**不是抓漏**：
华为已把招聘搬到新站 `career.huawei.com/cn`，老门户接口 `portalpub/getJob/newHr` 只剩 2 条残留。

找到新站岗位列表接口后重写爬虫，华为从 **2 条**变成 **288 条原始 / 219 条入库**，
并顺带把技能覆盖补到 **161/161（100%，此前缺「联邦学习」）**。

## 修复

### 华为爬虫改用新站接口
- `src/crawler/huawei.py` 重写，纯 `requests`，**无需登录 / 账号 / 浏览器**：

  ```
  POST https://apigw-dgg-b0.huawei.com/api/apig/channelhw/recruitmentPosition/pub/getJobPage?X-HW-ID=app_000000035886
  headers: x-jalor-tenantalias: hcm / x-referer / x-alb-gray: prod / x-language: zh_CN
  body:    {"curPage": N, "pageSize": 10, "jobType": "SR"}
  ->       data.pageVO {totalRows: 578, totalPages: 58} + data.result[]
  ```

- 字段映射：`jobId`→`hw_<id>`、`jobName`→标题、`jobFamilyName`→岗位族、`deptName`→部门、
  `workPlace`→城市、`lastUpdateDate`→发布时间。
- **坑**：接口用字面字符串 `"None"` 表示空值；`jobDesc` 常为 `None`，真 JD 在
  `mainBusiness`（标准职责）+ `jobRequire`（要求）；城市在 `workPlace` 而非 `cityName`。
- 口径与其它源一致：**只入技术族**（研发族 / 云服务族 / 质量与流程IT族），`--all` 可放开；
  `--stats` 只打印岗位族分布。
- 回归：`tests/test_huawei.py`（6 条，不发网络）。

## 已知限制
- **华为零技能率 44.8%（技术岗 46.9%）**，比其它源高。原因是「研发族」里包含大量
  硬件 / 结构 / 光学 / 制造工艺岗，JD 里不出现软件技能——属真实情况，**不放宽判定**。
- 老门户那 2 条岗位在新站已不存在，本轮被标记为「已消失」（`inactive_history_rows=2`）。
- 校招站仍需华为账号登录，本轮**未接入**；社招已覆盖 578 条，暂不需要账号。

# v1.5.0 求职闭环：简历经历分类 + 岗位收藏，并修复云端旧语料

把 v1.4.0 之后的 W18/W19 一并发版：新增**简历经历分类**与**岗位收藏夹**，并修复线上“代码已是新版、首屏仍是旧语料”的 Streamlit 缓存问题。语料、抽取与匹配指标保持不变；无破坏性接口变更。

## 新增
- **简历经历分类**：`ResumeProfile` 的经历新增 `kind`（`work` / `internship` / `project` / `other`）——LLM 优先判定，缺省时按章节标题（工作/实习/项目/教育）→ 角色关键词（实习/项目/工程师等）→ 组织关键词（公司/实验室/大学）兜底；教育经历明确跳过。简历页按类型分组展示；ATS 建议分别提示“缺工作/实习”与“缺项目”，全为 other 时不重复提示。
- **岗位收藏夹**：新增 `src/matcher/job_favorites.py` 纯函数——按“公司 + 归一化标题”去重、上限 20、`toggle_favorite` / `remove_favorite` / `is_favorited` / `?fav=job_id,...` 编解码、按 job_id 从语料还原。差距报告页与简历推荐 Top10 增加“⭐ 收藏该岗位”，侧边栏跨页面查看、移除并导出 JSON；收藏写进链接，刷新/书签不丢。

## 修复
- **云端旧语料（根因：缓存未失效）**：`@st.cache_data` 只看函数代码与显式参数，不感知 `data/processed/jobs.jsonl` 被替换。新增 `app._file_fingerprint()`（路径 + `mtime_ns` + `size`），接入 `load_core` / `load_engine` / `load_jobs` / `extract_corpus` / `_recommendations` 的缓存键；`extract_corpus` / `_recommendations` 同时绑定技能词表指纹。注意 Streamlit **会跳过以下划线开头的参数**，缓存键参数不能命名为 `_mtime_ns` / `_size`。推送 `086602a`、`d5b8936` 后线上验收为 **5832 条 / 81 家**（旧版 4582 / 78）。
- **收藏夹文案**：空收藏提示不再把 `?fav=…` 链接参数直接展示给用户（此前会被当成乱码）；改为“收藏会保存在当前页面链接中，刷新或收藏书签都不会丢”，底部说明与按钮帮助同步去掉“链接参数”措辞。`test_app_runs_without_exception` 增加断言，收藏夹简介不得包含 `?fav` / `fav=`。

## 已知限制
- 收藏夹仅存于当前页面链接，**没有服务端存储**：换浏览器/清空链接会丢失；上限 20 条。
- 简历经历分类是“LLM 优先 + 正则兜底”，复杂排版仍可能归到 `other`，页面保留原始经历文本供核对。
- 收藏夹是求职短名单，不含投递状态、提醒或岗位订阅。

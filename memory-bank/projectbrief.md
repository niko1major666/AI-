# 项目简报（Project Brief）

## 项目名称
AI 岗位技能差距分析系统（ai-skill-gap）

## 项目定位
面向**非科班与转行求职者**的个人项目，分析目标 AI 岗位所需技能，与自身简历对比，输出技能差距报告与学习优先级。体现 **NLP 信息抽取 + 语义匹配 + 工程落地**能力。

## 核心需求与目标
1. **数据采集**：采集真实 AI 岗位 JD（大厂 + AI 创业公司），当前 4776 条 / 79 家公司
2. **技能抽取**：从 JD 抽取细粒度技能实体（161 个标准技能）
3. **语义匹配**：简历/技能列表 → 目标岗位技能，计算匹配度
4. **差距诊断**：缺失技能 + 优先级（P0/P1/P2）+ 行业重要度 + 学习难度 + 学习资源；AI 解读按简历解析出的专业给迁移建议（无专业不展示）
5. **前端展示**：Streamlit 三页面（技能图谱 / 简历匹配 / 差距报告）
6. **简历解析**：正则 + DeepSeek LLM 增强（姓名、工作经历等）+ ATS 改进建议
7. **云端部署**：Streamlit Community Cloud 免费部署（依赖分层 + 数据入库 + secrets 管理）

## 项目范围（Source of Truth）
- 一条完整 NLP 落地链路：数据采集 → 技能抽取（双路）→ 语义匹配（双路）→ 差距诊断 → 前端可视化
- 差异化亮点：技能重要度由 4776 条真实 JD 的需求频率驱动
- 诚实标注所有实验结论（含失败案例）

## 作者背景
非科班大四学生，投递 AI+ 岗位。

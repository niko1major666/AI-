# v1.3.0 求职闭环与评测加固

从「诊断差距」走到「怎么补、投哪里、怎么交」：新增规则版学习路径、简历补强建议、报告导出、多岗位对比、反向岗位推荐、技能画像与公司×技能矩阵；同时把评测基线、语料快照、覆盖率门槛与 nightly 全量接进 CI，改词表/改匹配策略不再静默退化。

## 新增
- **规则版学习路径**（`src/matcher/learning_path.py`）：P0/P1/P2 三阶段，52 个技能 / 64 条先修关系拓扑排序，难度→学时（2/4/8/16/24h）、周数向上取整；先修若落在后续阶段自动前移，缺口外前置只给 `prereq_note`。**无 API key 也能出计划**（LLM 解读为可选增强）
- **报告导出**（`src/app/report_export.py`）：Markdown + Word（python-docx 懒加载），`safe_filename` 清洗文件名；报告写 `st.session_state`，避开 `download_button` 点击 rerun 后按钮消失的坑
- **多岗位对比**（`src/matcher/job_compare.py`）：各岗匹配度 / P0 数 / 共性缺口 / 各岗独有缺口 / 优先投递建议
- **反向岗位推荐**（`src/matcher/job_recommender.py`）：简历技能扫全语料，按「公司+标题」去重、must/nice 加权，Top 10 + 最该补的 3 项
- **技能画像**（`src/matcher/strength_profile.py`）：按类别的需求加权覆盖率 + 最大短板；零需求技能按 0.001 权重计入分母，避免冷门类别虚高到 100%
- **公司 × Top 12 技能矩阵**（`src/data/skill_stats.py`）：技能图谱页用 Streamlit `ProgressColumn` 呈现，未引入 matplotlib
- **简历补强建议**（`src/data/resume_advice.py`）：简历原文命中 → 改写要点；未命中 → 小项目建议；数字一律 `XXX` 占位符，**不编造经历**

## 改进
- **知识库扩充**：技能 147 → **161**（视觉语言模型 5.87%、Function Calling 4.60%、MCP 2.75%、视频生成 2.58%、扩散模型 2.36%、偏好对齐、昇腾、长上下文、DeepSeek、Qwen/Llama/GLM、世界模型、具身智能、LangGraph、Dify 等 16 项高频缺失项），合并 2 个零命中冗余项；学习资源 11 → **106**（Top 80 需求技能覆盖 77 项）
- **`Skill.skip_extract`**：解析侧词表与抽取侧词表分离，修正裸「量化」误匹配（6.31% → 1.07%，importance 4→2），简历输入「量化」仍可解析为模型量化
- **must/nice 判定改用 JD 原文三级规则**（`src/matcher/jd_requirements.py`：句内触发词 → 章节标题 → 全行业占比兜底），57.0% 岗位可判出 ≥1 项硬性要求（1.48 项/岗）
- **零技能岗位代理兜底**（`src/matcher/job_neighbors.py`）：1085 条零技能岗位中 98.7% 可用同公司相似岗位代理（中位 4 项），页面标注来源，不再误显示「已覆盖全部技能」
- **匹配度加入岗位内强调度** `base × (1 + ln tf)`（45.2% 岗位存在 tf≥2 的技能）
- 简历解析按文本缓存，DeepSeek 超时 90s → 25s 并重试一次（冷启动不再卡死）
- `rule_baseline.extract()` 单次扫描同时产出 span 与词频，避免重复扫描

## 评测与 CI
- **指标回归写进测试**：抽取 F1（test 0.9565 / 全量 0.9123，容差 1pt）、TF-IDF Recall@5（skill_pair 0.9750 / resume_sentence 0.2200，容差 2pt）
- **语料快照**：4582 条 / 78 家 / 4472 唯一「公司+标题」，字段完整性与 `job_id` 唯一性；slow 用例校验 160/161 技能覆盖与零技能占比区间
- **`scripts/eval_all.py` → `docs/metrics.md`**：抽取 / 匹配 / 覆盖 / 阈值四节，无时间戳可 diff；CI 在 main 上重跑并 `git diff --exit-code` 拦截过期指标
- **`scripts/validate_kb.py`**：词表 id 唯一、别名冲突、类别/难度合法 + 资源 `skill_id` 存在性、重复 title、非法 url；CI 前置执行（另加 `compileall`）
- **CI 加固**：覆盖率门槛 **55%**（实测 58%）、Python **3.10/3.12** 矩阵、pip 缓存、concurrency 取消旧任务；`slow` 用例（全语料遍历）交给 `.github/workflows/nightly.yml` 每日全量
- **测试 131 → 201**（199 快测 + 2 slow），全量约 40s；新增 AppTest 覆盖多岗对比、简历页技能画像与 Top10 推荐、导出按钮存在性

## 修复
- `is_must` 原按「全语料需求占比 ≥ 40%」判定，实测最高仅 36.2% → P0 恒为空
- 零技能岗位原误判为「已覆盖全部技能」
- 差距报告页循环变量覆盖 `label`，导致「P2 可选」被当作目标岗位传给 AI 解读（v1.2.0 已修，v1.3.0 起由 AppTest 回归覆盖）

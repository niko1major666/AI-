# v1.7.2 美团校招/实习接入（含 5 条新增岗位）+ 工程经验沉淀

新增美团校招 / 实习爬虫并正式接入构建流水线。全量抓取 311 条技术类岗位，
但按 `text_hash` 与现有语料比对后发现**其中 301 条与社招 JD 完全重复**，真正新增只有 5 条——
因此这是一个小版本：语料 **5832 → 5837**，公司数不变。

## 新增

### 美团校招 / 实习爬虫
- 新增 `src/crawler/meituan_campus.py`：PC 版 `jobType` 过滤（`1`=校招、`2`=实习）。
- **无需登录 / cookie / 签名**（2026-11 实测，与社招一致）。只需一轮查询 token
  （`u_query_id` / `r_query_id`）整轮复用——每页换新会让分页退回第 1 页。
- 字段映射：`name`→标题、`jobDuty` + `jobRequirement`→JD、`cityList`→城市、
  `refreshTime`→发布时间（走 `fmt_publish_time`）、`jobUnionId`→`mtc_<id>`（缺失时用标题+城市哈希兜底）。
- 口径与社招一致：**只入技术类**；`jobFamily` 为空时用标题技术词兜底并打印丢弃分类。
- 三处注册：`merge_jobs.FILES` / `SOURCE_BY_FILE`、`recrawl_all.CRAWLERS`。
- 回归：`tests/test_meituan_campus.py`（7 条，不发网络请求）。

### 工程经验沉淀
- 新增 [`memory-bank/lessons.md`](../../memory-bank/lessons.md)：把本轮踩到的 6 个"看起来对、实际错"的判断
  写成可复用清单（分页外推、去重键、派生文件过期、半注册源、恒真门禁、凭据边界），每条附"当时怎么发现的"。

## 为什么要特别说明"只加了 5 条"

抓到的 311 条技术类岗位里：清洗后唯一 JD 306 段，其中 **301 段（98.4%）与社招 `meituan` 完全重复**。
即**美团校招技术岗与社招共用同一套 JD**。`preflight_new_source.py` 体检为 PASS
（0 个 id 冲突、0 源内重复、技能覆盖仍 160/161、must 占比 59.9%），所以可以安全并入；
但收益天花板很低，后续再从这里扩量的意义不大。详见 `docs/source-triage-v1.7.md` §7。

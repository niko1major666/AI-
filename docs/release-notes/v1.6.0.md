# v1.6.0 数据新鲜度 + 来源健康 + 简历隐私边界

把迭代 8 的**数据新鲜度 / 来源健康**与简历侧的**隐私告知、PII 脱敏、上传限制**一并发版。语料仍为 5832 条 / 81 家，抽取与匹配指标零 diff；测试 296→310。

## 新增

### 数据新鲜度
- 岗位新增 `source` / `crawl_time` / `first_seen_at` / `last_seen_at` / `is_active`：`merge_jobs.py` 按文件名映射来源、按源 CSV mtime 写抓取时间，修正此前统一写成 `local_csv` + 构建时间的问题。
- 新增 `src/data/freshness.py`：`first_seen_at` 跨构建保留，`last_seen_at` 取源抓取时间，往期出现、本轮未出现的 job_id 标记 `active=false`；状态落 `data/processed/job_freshness.json`（5832 条全部 active）。
- 差距报告岗位下拉显示“N 天前更新”，支持「全部 / 近 7 天 / 近 30 天」筛选；超过 30 天未再抓到的岗位提示“可能已下线，投递前请到官网确认”。简历推荐 Top 10 增加“更新”列。

### 来源健康
- 新增 `src/data/source_health.py` + `scripts/source_health.py`，生成 `docs/source_health.md`：14 个来源的岗位量、公司数、最新抓取、发布时间覆盖、零技能率、超期/已消失数量与健康状态。
- 当前基线：**5832 条 / 81 家 / 14 来源**；发布时间覆盖 **72.0%**；超 30 天未更新 **0 条**；零技能 **21.5%**；9 个来源正常、5 个关注（快手/小红书/英文科技岗/DeepSeek/华为，均因发布覆盖或零技能率触发，不是抓取失败）。
- CI 在 main 上重跑来源健康报告并 `git diff --exit-code`，防止词表/数据源/构建逻辑变化后报告陈旧。

### 简历隐私与上传边界
- 新增 `src/data/privacy.py`：统一隐私说明、上传校验、PII 脱敏与会话配额。
- 简历页上传前必须勾选**隐私说明**；DeepSeek 增强改为**单独 opt-in、默认关闭**。不开启时只在本服务进程内用正则解析，不调用第三方 API。
- 开启 AI 增强后：仅发送简历**前 6,000 字**；发送前自动隐藏邮箱、手机号、18 位身份证号、16–19 位银行卡号、带标签的微信/QQ/WhatsApp 与详细住址。页面展示本次隐藏类别与数量。
- 联系方式只认本地正则：LLM 收到的文本已脱敏，其返回的 `email` / `phone` 不再覆盖本地结果。
- 上传限制：单文件 ≤5 MB（`.streamlit/config.toml` + 应用层双重校验）、PDF ≤30 页、解析文本 ≤50,000 字、DOCX 解压后 ≤50 MB（防 zip bomb）、每会话 ≤10 次 AI 简历解析。
- 简历解析缓存从跨会话的 `st.cache_data` 改为 `st.session_state` 会话级：同一份简历 rerun 不重复调 LLM，但不会把简历文本/解析结果留在全局缓存中。
- 新增 [`docs/privacy.md`](../privacy.md)，完整说明处理目的、外发字段、保留方式、用户控制与剩余风险。

## 行为变化
- **AI 简历增强默认关闭**：此前配置 key 即自动调用；现在必须用户主动勾选，否则走本地正则。关闭不影响技能提取、ATS 建议、技能画像与岗位推荐。
- 未同意隐私说明时上传控件禁用，且即使收到文件也不会读取内容。
- 联系方式不再采用 LLM 返回值；复杂排版下若正则未识别邮箱/手机号，会如实提示缺失，而不是让模型猜测。
- “AI 解读 + 学习计划”仍只发送岗位/技能/匹配统计；从简历解析出的专业名称仅在用户开启简历 AI 增强时才会附带。

## 已知限制
- PII 脱敏是确定性正则，无法覆盖无标签地址、姓名嵌入正文、图片文字或特殊格式证件号；姓名、学校、公司、项目经历等正文仍可能识别个人，AI 增强**并非匿名化**。
- DeepSeek 的请求处理与保留受其自身条款约束；应用只能保证发送前脱敏与字段最小化，不能承诺第三方删除。
- 源 CSV 本身不含抓取时间，`crawl_time` 用文件 mtime 近似；首次启用新鲜度状态时以当期各源抓取时间为准，之后增量维护。
- 应用无账号体系与自建简历存储；无法按用户检索/删除历史会话，刷新或关闭页面即结束会话。

1. **快手发布时间**：修补后发布覆盖率应从 17.3% 显著上升，且 `docs/source_health.md` 重跑后数字同步更新（允许 diff，但必须在 release notes 里解释）。
2. **零技能归因**：对快手 / 小红书各抽 40 条零技能岗位，按「非技术岗 / 词表缺词 / 抽取漏」三类归档，产出比例与改名建议；**归因完成前不改阈值、不改 `skill_taxonomy.yaml`**。
3. **新增数据源**：接入前必须跑 `scripts/preflight_new_source.py`（job_id 冲突 / 跨源重复 / 公司写法分裂 / 零技能率 / must 偏移），结果写进本文件。

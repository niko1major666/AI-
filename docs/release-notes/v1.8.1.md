# v1.8.1 华为数据源调研结论（渠道已迁移）

补丁版：只新增调研结论与复现方法，**不改代码、不动语料**。

## 结论

华为岗位只有 2 条**不是我们抓漏**，而是华为把招聘搬到了新站：

| 通道 | 现状 |
|---|---|
| 老门户接口（现爬虫用的 `portalpub/getJob/newHr`） | **全站 2 条**（API 与浏览器双向确认） |
| 新站 `career.huawei.com/cn/social-recruitment` | 页面显示 **共 269 个职位**，但列表由前端渲染，接口未暴露 |
| 新站校招页 | 明确要求**登录华为账号** |
| 51job 第三方通道（仓库既有实验） | 9 城市仅 3 条 AI 岗且无完整 JD |

已确认可用的新站接口：`calculateSocialRecruitmentJob`（`X-HW-ID` + `{"jobType":"SR"}`）
→ 返回 175 个**类目**（含 `familyCount`），但**不返回岗位**；列表接口未在页面 XHR 与 JS bundle 中出现，
页面 HTML 也没有服务端渲染的岗位数据。

## 影响

- `huawei` 源在 `docs/source_health.md` 里仍是 2 条 / 发布覆盖 0% / 「⚠️ 关注」——
  这是**渠道迁移**导致，不是抽取器或词表问题。
- 复现方法写进 [`docs/source-triage-v1.7.md`](../source-triage-v1.7.md) §8：
  一条看老接口 `pageVO.totalRows`，一条看新站类目接口，一条确认页面是否 SSR。

## 后续三条路（需产品决策）

1. **浏览器渲染抓取**（无需账号）：能拿 269 条，慢且依赖 DOM。
2. **继续逆向新站列表接口**：不确定能否成功。
3. **账号登录校招站**：校招岗位必须登录；账号对社招无帮助。

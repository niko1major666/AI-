# 产品上下文（Product Context）

## 为什么存在
作者（非科班转行者）在转投 AI 岗位过程中，发现缺乏一个能回答「**目标岗位到底需要哪些技能、我还缺什么、该先补什么**」的工具，于是从零搭建本系统。

## 要解决的问题
1. 求职者不知道目标 AI 岗位的真实技能需求（尤其非科班）
2. 不知道自己和目标岗位的差距在哪里
3. 不知道该按什么顺序补技能（学习路径规划）
4. 简历在 ATS（招聘系统）筛选中可能被漏掉（缺关键词、信息不完整）

## 如何工作
```
数据采集 → 技能抽取 → 语义匹配 → 差距诊断 → 前端展示
raw CSV → 规则基线/BERT-NER → TF-IDF/BGE → 打分+优先级 → Streamlit 三页面
```
用户流程：
1. 「技能图谱」页：了解行业技能结构（公司筛选、高频技能、共现网络）
2. 「简历匹配」页：上传简历 → 结构化解析（正则+LLM）→ 技能提取 → ATS 建议
3. 「差距报告」页：选公司 → 搜索岗位 → 选目标岗位 → 生成差距报告（缺失技能 + 优先补充建议）

## 用户体验目标
- **直观**：卡片式 UI、星级展示（重要度/难度）、P0/P1/P2 分级
- **可信**：所有量化指标有据可依（数据驱动 importance、真实评测数据）
- **可落地**：不止给差距，还给「优先补什么 + 怎么补 + 学习资源」
- **诚实**：如实标注失败实验和局限，不夸大

## 关键约束
- 面向个人使用（本地 + Streamlit Community Cloud 免费部署），不追求多租户/高并发
- 中文为主（含英文岗位的标题翻译）
- 成本敏感（CPU 推理、免费 LLM 额度）
